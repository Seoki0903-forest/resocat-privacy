1. 화면 인식과 권한
이용자가 인식 시작을 선택하고 Android 화면 공유 동의를 승인하면 화면 프레임을 기기 내 OCR로 처리하여 젠레스 존 제로 디스크 옵션을 읽고 판정 결과를 표시합니다. 화면 전체 공유를 선택하면 다른 앱의 민감한 내용도 인식 범위에 들어갈 수 있으므로 인식 중에는 비밀번호, 결제, 메시지 등 민감한 화면을 열지 마세요. 화면과 인식 결과는 개발자 서버에 업로드하거나 녹화 파일로 저장하지 않습니다. 인식 중지 또는 Android의 화면 공유 중지를 선택하면 캡처 서비스가 종료됩니다.
다른 앱 위에 표시 권한은 판정 오버레이를 표시하는 데 사용합니다. 접근성 서비스, 마이크 녹음, 연락처 및 위치 권한은 사용하지 않습니다.

2. 기기에 저장되는 정보
판정 방식, 표시 설정 등 사용 환경과 내려받은 비교 데이터는 기기의 앱 저장 공간에 저장합니다. 앱 데이터 삭제 또는 앱 제거 시 해당 로컬 데이터가 삭제됩니다. Android 시스템 백업은 비활성화되어 있습니다.

3. 외부 통신과 SDK
비교 데이터 업데이트를 위해 GitHub의 HTTPS 서비스를 사용합니다. 이 과정에서 GitHub는 요청 처리에 필요한 IP 주소와 일반적인 접속 정보를 처리할 수 있습니다. 화면이나 OCR 결과를 업데이트 요청에 포함하지 않습니다. GitHub 개인정보처리방침: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement
한국어 문자 인식에는 Google ML Kit를 사용하며 이미지 인식은 기기에서 수행합니다. ML Kit는 진단 및 사용량 분석을 위해 기기·운영체제·앱 및 SDK 버전, 설치별 식별자, API 사용·성능·오류 등의 정보를 Google로 전송할 수 있습니다. Google의 안내: https://developers.google.com/ml-kit/android-data-disclosure
Google 개인정보처리방침: https://policies.google.com/privacy

4. 계정, 광고 및 결제
현재 버전은 회원가입, 로그인, 광고 SDK 및 앱 내 결제를 제공하지 않습니다. 향후 광고 등 데이터 처리 방식이 변경되는 경우 이 방침과 스토어 고지를 업데이트합니다.

5. 보유, 삭제 및 문의
개발자는 화면 영상과 판정 결과를 수신·보관하지 않습니다. 로컬 설정과 비교 데이터는 앱 데이터 삭제 또는 앱 제거로 삭제할 수 있습니다. 외부 서비스가 처리하는 진단·접속 정보의 보유 및 권리 행사는 각 서비스의 정책에 따릅니다. 개인정보 관련 문의는 contact@seokiapps.com으로 연락해 주세요. 문의 시 제공한 이메일과 내용은 문의 응대 목적으로 처리합니다.

6. 대상 및 변경
이 앱은 젠레스 존 제로 이용자를 위한 비공식 보조 도구이며 어린이를 대상으로 제작하지 않았습니다. 개인정보 처리 방식이 변경되면 공개된 방침의 시행일과 내용을 갱신합니다.
